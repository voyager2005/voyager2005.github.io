# Personal Portfolio Website

This repository hosts the source code for my personal portfolio website. It serves as a space to share my academic research, industry internship work, technical writings, and casual projects.

## Site Structure

- **Main Page**: A brief introduction to my interests, background, and research mentors.
- **Experience**: Details of my technical work experience, including my multiphysics AI research internship at Shell.
- **Projects**: Highlights of featured engineering projects like Sensera (a privacy-first health record system) and MAVERIC (autonomous mobility perception stack).
- **Publications & Writings**: Links to my research papers and beginner-friendly guides on deep learning.
- **Interactive Resume**: A web-viewable, printer-friendly version of my one-page resume.

## Technologies Used

- React
- Vite
- Custom Vanilla CSS

## Running Locally

To run the development server locally, install the dependencies and start the Vite dev environment:

```bash
npm install
npm run dev
```

To compile a production build of the website:

```bash
npm run build
```
